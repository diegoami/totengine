## Material limits and reviewer focus

This is a discovery/design/planning release. The prototype runs authored
fixtures, even when it renders installed artwork. No human game-session driver,
playable browser/desktop, portable atlas decoder, desktop package, WASM build,
scenario compatibility or sustained human campaign is delivered here.

The reference identity is the installed patched executable; unpatched UI parity
is unproven. Discovery retains explicit gaps in later government, slider
algorithms, transport, visibility, late space, conversation/event/Lua and
scenario-start branches. The proposed safe revolution Escape redesign is still
an unaccepted later alternative; it is outside the first slice. A prior picture
remaining after failed native import does not prove atomic state preservation.

The first implementation slice uses Original-profile generated surface games,
existing built-in opponents and engine checkpoints. Original SAV/SCN import,
full city economics, government/diplomacy, sea/air/cargo and multiple maps are
later work. Reaching an unsupported required decision must never silently
choose for the human; promote prerequisites when needed for a useful route.
Round-boundary research delivery and subsequent-city science behavior require
explicit testing in #127 before either playable client can claim that route.

The audit finds that current observer payloads include spectator/all-civ data;
#128 requires filtered human views before serialization. Current synchronous
Game processing and autonomous checkpoints are foundations, not an already
resumable human driver. SDL2 is a feasibility candidate, not a chosen/validated
production toolkit. No package installation is required merely to review this
planning release.

Full original AI #117 and external-AI infrastructure remain gated behind the
playable client. Decision 0003's Player observation/private RNG boundary remains
unchanged. Stories #126–#131 belong to the following first playable milestone;
#94/#125 retain complete-client work beyond it. No later version/count/date or
full native parity is promised. The owner alone launches independent review.
