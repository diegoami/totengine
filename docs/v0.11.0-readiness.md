## Decisions and limitations for the eventual milestone reviewer

The scope is discovery, reviewed design and implementation planning. It does
not deliver a playable client. The HTML prototype executes authored fixtures;
its format is not a production-toolkit decision, checkpoint or native SAV.
The original-AI completion program #117 and external-AI infrastructure remain
after the playable client. Decision 0003's observation boundary is unchanged.

Reference identity is the installed patched executable; unpatched UI
compatibility is unproven. Some input behavior depends on preferences and focus.
The isolated revolution Escape behavior differs from the proposed safe
cancellation; this difference needs owner acceptance. Native imports retaining
the prior picture do not establish complete state preservation. Full slider,
visibility, government, transport, late-space, event/Lua and scenario-start
branches remain explicitly unverified in the inventory/contracts.

Do not mark #107 complete, bump the version or call the milestone from the
existence of this file. Once owner design/scope decisions are recorded and the
accepted decomposition is in the live queue, finish the release notes/version
candidate and follow [milestone-review.md](milestone-review.md). The owner,
not the implementation session, launches the independent milestone review.
