# v0.13 preparation — city workers and specialists

Work in progress for milestone 11 / #135–#137; not a review candidate or release.
v0.12.0 remains released. Design and acceptance:
[city-citizens milestone](ui/city-citizens-milestone.md).

The shared engine/controller now exposes an own-city radius, worked/available
tiles and yields, specialist roles, signed food storage/growth threshold,
support and live finance/mood feedback. O opens the city workspace; arrows and
Space select/toggle tiles; clicking a tile edits immediately; specialist buttons
cycle roles; PageUp/Down navigate own cities; Escape returns without undoing
accepted edits. Required research still blocks unrelated edits. Production keeps
its existing explicit picker and cancellation leaves the item unchanged.

`engine::citizens` uses the existing original-checked allocation, availability,
yield/finance/happiness refresh. Human named founding now allocates citizens as
part of its recorded order, so opening/reading a city is inert; autonomous
`FoundCity` is unchanged. New worker/specialist orders and stable city identities
are canonical transcript/checkpoint inputs. Edits neither collect treasury nor
advance growth, production, turn or either game RNG. Checkpoint format 2 remains
bound to exact engine version; use v0.12 binaries for v0.12 human checkpoints.

Reproduce numeric edit evidence with Unicorn 2.1.4 installed outside the repo:

```sh
CIVTOT_HOME=/path/to/CIVTOT PYTHONPATH=/path/to/unicorn \
  python3 tools/citizens_check.py --gold /tmp/citizen-edits.json \
  --vectors /tmp/citizen-edit-vectors.txt
cargo test -p engine --lib citizens::tests
cargo test -p engine --lib human::tests
```

and fresh-output-folder requirements remain applicable. The population-five
fixture is seed 7, 80×50, two civilizations, human 1, difficulty 0; it reaches

## Remaining acceptance and limits

Owner route on each client: load/start a supported city, open its workspace,
remove and restore a worker, observe food/mood/output changes, exercise the three
specialist roles in a population-five city, cancel production, navigate cities,
save after an edit, reload and take the next assignment. Report actual blockers
and fix them before a milestone candidate. v0.12's human confirmation is not
reused as evidence that the owner tried the new controls.

Buying/selling, production-switch penalties, full improvement/support/happiness
panels, government/diplomacy, import/scenarios/multiple maps and sustained full
campaigns remain later work. Citizen art uses measured generic crops and authored
work/selection markers, not full native clothing/mood/style selection. The engine
has sixteen stored editable specialist roles; later fixed entertainer slots are
not offered as mutable role controls. Automatic allocation uses the existing
native kernel; an empty-tile click without a spare citizen requests native-style
automatic reassignment. Full original AI remains gated behind complete client
delivery. The owner launches independent review; no tag before AGREE.
