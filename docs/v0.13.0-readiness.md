## Implemented scope

The shared engine/controller supplies an own-city radius, worked/available tiles
and yields, specialist roles, signed food storage/growth threshold, support and
live finance/mood feedback. Manage city opens the workspace. Worker/specialist
edits commit immediately through recorded commands. City closing/navigation and
inspection are inert; production retains its explicit accept/cancel picker.
Required decisions still block unrelated gameplay.

`engine::citizens` reuses the original-checked allocation, availability, yield,
finance and happiness kernels. Named human founding allocates citizens during
its order so reading a city is inert; autonomous FoundCity is unchanged. Edits
do not collect treasury or advance growth, production, turn or either game RNG.
Checkpoint format 2 remains bound to engine/resource identity; use v0.12 binaries
for v0.12 human checkpoints.

The input correction changes presentation/controller behavior, not engine rules
or checkpoint format. Own-unit selection takes precedence in both modes. A
stack chooser retains slot+entity identity; rendering and hit testing share one
visible member per stack. A ready selected sprite blinks in Moving and remains
hittable while hidden. Exhaustion selects another ready unit or returns to
Viewing/End of turn. New human turns and resolved required choices select a
ready unit. Human end-turn advancement remains explicit. Supported original
bindings and remaining differences: [original controls](ui/original-controls.md).

## Reproduction

Packed city-edit evidence (Unicorn 2.1.4 installed outside the repository):

```sh
CIVTOT_HOME=/path/to/CIVTOT PYTHONPATH=/path/to/unicorn \
  python3 tools/citizens_check.py --gold /tmp/citizen-edits.json \
  --vectors /tmp/citizen-edit-vectors.txt
cargo test -p engine --lib citizens::tests
```

Generate private fixtures through normal recorded gameplay:

```sh
CIVTOT_HOME=/path/to/CIVTOT TOTENGINE_SELECTION_OUT=/private/selection \
  cargo test -p totui generated_selection_fixture -- --ignored --nocapture
CIVTOT_HOME=/path/to/CIVTOT TOTENGINE_CITIZENS_OUT=/private/city \
  cargo test -p totui generated_population_five_city_fixture -- --ignored --nocapture
CIVTOT_HOME=/path/to/CIVTOT TOTENGINE_ENCOUNTER_OUT=/private/encounter \
  cargo test -p totui generated_land_encounter -- --ignored --nocapture
```

The new pair is Original Rules seed 7, 80×50, two civilizations, human 1,
difficulty 0: two warriors at different locations with moves remaining at turn
12. The fixture records the initial stack and expected movement/skip/next-turn
checkpoints. It uses no world/RNG injection. The mature city uses the same setup
and reaches population five at turn 72. Navigation uses the seed-2 encounter's
two own cities.

Set `TOTENGINE_SELECTION_FIXTURES=/private/selection`,
`TOTENGINE_CITIZENS_FIXTURES=/private/city`,
`TOTENGINE_NAVIGATION_FIXTURE=/private/encounter/last.cth` and
`TOTENGINE_ENCOUNTER_FIXTURES=/private/encounter` in `tools/check_client_*`.
Browser additionally needs its isolated host origin/save folder and Playwright;
`TOTENGINE_BROWSER_EXECUTABLE` can select an installed Chromium executable.
Linux uses `TOTENGINE_CLIENT_BINARY`; Windows accepts `-Binary`/`-Work` and
`-SelectionOnly` for focused checks. Fresh output/save folders avoid overwrite
collisions. `check_client_selection.{cjs,py,ps1}` is invoked by each adapter's
checker; it never substitutes direct game mutations for pointer/keyboard input.

## Remaining acceptance and limits

The owner must try the revised unit selection/movement/blink behavior in both
clients, including selecting another ready unit and an exhausted one. The new
city route also requires actual owner results: remove/restore a worker, observe
food/mood/output, exercise all three specialist roles in a population-five city,
cancel production, navigate cities, save/reload and make the next assignment.
No further human outcome has been reported for this build. v0.12's confirmation
is not reused. Do not open a milestone review candidate before this gate passes;
the owner launches independent review and no tag precedes AGREE.

Buying/selling, production-switch penalties, full city panels, government,
diplomacy, import/scenarios/multiple maps and sustained full campaigns remain
later work. Citizen art is generic; native clothing/mood/style selection and
complete original layout parity are not claimed. Sixteen stored specialist
slots are editable; later fixed entertainer slots are not offered as mutable.
Automatic allocation retains the native-style spare-citizen behavior. Full
waiting queues, fortification/sleep and native mouse-edge arrows remain later
unit work. The complete original AI remains gated behind full client delivery.
