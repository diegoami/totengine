# v0.18.0 — science, rates and government on both clients

**Candidate, not released.** Release state lives on the milestone issue; this file
records scope, checks and limits. Previous tag: v0.17.0
(`70dea8d7e61e74125c9faa027bf7a6abb7cbdaff`). Milestone 16 / #194–#196.

## Scope

- **Reference (#194):** native caps, slider redistribution (with the remembered
  opening value), government eligibility, anarchy resolution and the human research
  list are decoded from the unpatched `civ2.bak` and executed natively; vectors and
  rationale are in [evidence §Rates, revolution and government selection and
  §Research selection](evidence/README.md). The second-government fixture author is
  `tools/government_fixture.py`; loading it in the original game is untested.
- **Engine (#195):** validated rates (`Command::Rates`), voluntary revolution,
  required government chooser and rate review replayed through checkpoints,
  native anarchy resolution, the native human research list and a checkpointed
  research goal. `Phase::UnsupportedGovernment` is removed. Read-only view fields
  (`goal_choices`, `anarchy_choice_turn`, `revolution_choice_turn`) and
  `HumanSession::preview_rates` serve the clients.
- **Clients (#196):** one shared controller (`totui::client`, `routes.rs`) with
  Shift+T rates, Shift+R revolution, F6 science advisor, the required chooser and
  review. Browser (`play.js`) and desktop (`desktop.rs`) forward the new keys.
  Design and decisions: [science-government-milestone.md](ui/science-government-milestone.md).

Compatibility: engine/checkpoint version 0.18.0; human research lists changed (open
demo: nine topics); the authored golden differs only in its version header.

## Checks run on the candidate

- `make test fmt clippy` with `CIVTOT_HOME` set: 285 Rust tests passing (8 ignored,
  install-backed recorders), the Python suite (44 tests), the full golden corpus,
  `cargo fmt --check` and strict Clippy. Desktop-feature strict Clippy, and 40
  client tests with the desktop feature.
- Native vectors: caps 256, redistribution 621, remembered-value 414, eligibility 144,
  anarchy resolution 528, research list 48 states (all executed natively; see evidence).
- **Real input on both clients, one recorded route:** the ignored
  `generated_government_route` test records 69 steps and nine checkpoints; the
  desktop client (SDL under a private Xvfb with XTest keyboard/pointer) and headless
  Chromium (real keyboard and mouse) replay it, check the on-screen dialog title
  after every step and obtain byte-identical checkpoints, including save/reload
  while the government chooser and the rate review are pending.
  Summary: [client-government-route-v1.json](evidence/client-government-route-v1.json).
- Rates quote cost: 8 µs (release) / 75 µs (debug) per quote on a generated 80×50
  game with one city; scales with the civ's city count (not re-measured for a mature empire).

Reproduce the route:

```sh
export CIVTOT_HOME=/path/to/CIVTOT
TOTENGINE_GOVERNMENT_OUT=/tmp/govroute cargo test -p totui --lib generated_government_route -- --ignored
cargo build -p totui --features desktop --bin totdesktop --bin totplay
# desktop (needs Xvfb, libX11, libXtst)
TOTENGINE_GOVERNMENT_FIXTURES=/tmp/govroute PYTHONPATH=tools python3 tools/check_client_linux.py
# browser: start totplay on a private port with TOTENGINE_SAVES=<empty dir>, then
TOTENGINE_GOVERNMENT_FIXTURES=/tmp/govroute TOTENGINE_CLIENT_SAVES=<same dir> \
  TOTENGINE_CLIENT_ORIGIN=http://127.0.0.1:<port> node tools/check_client_browser.cjs
```

## Not claimed

- No Windows input run, no packaged archives, no owner acceptance of the new routes
  on either client; those belong after the independent review.
- The second government cannot be reached from a generated start (only Despotism is
  eligible); the multi-government chooser is covered by engine tests, not by real input.
- Undecoded native behavior: prompt timing, the recommender's random consumption,
  the exact research "enabled" byte, the revolution scenario restriction
  (`0x607640 & 0x80` / `0x5f5e50 & 0x10`), `0x4bf9b6` effects and AI government choice.
- Escape on the revolution question cancels, the chooser has no cancel and Escape in
  the review resets: deliberate owner-approved differences from the original (see
  [screen contracts](ui/screen-contracts.md)); native Cancel behavior is untested.
- The reviewed PRs #239–#242 merged without individual review; this milestone review
  is their review.
