## Implemented boundaries

No reference save is used to initialize a generated campaign. Surface terrain
comes from our generator; region assignment, fertility estimates and default
initial resources are explicit engine policy. Decoded start placement and
the existing native-checked economy/combat/research kernel consume those
inputs. Original new-game initialization or original-AI equivalence is not
claimed. See `docs/generated-campaign.md` for every default and limit.

The `.ctc` file is a replay checkpoint: setup/version/Rules identity, order
transcript and world fingerprint. Restore reconstructs both world and private
AI state by replaying the recorded AI prefix. Cost is O(recorded rounds).
Native `.SAV` compatibility and instant state snapshots are separate work.
Observed one/zero remaining civs and turn limits are not original victory
rule claims.

The authored Rules fixture is project-authored synthetic data. Its 100-round
run reaches 20 cities, 27 population, 28 units and 35 advances, checksum
`b22e4340b6ab8bf6`. The user-supplied Original Rules run reaches 16 cities,
39 population, 53 units and 35 advances, checksum `76814781c4e92589`.
Both independently replay and continue identically across checkpoint restore.
Their numeric trajectories and input hashes are retained in evidence;
neither is an original-game AI comparison.

## Generator comparison scope

The protocol was frozen before collecting the expanded cohort and v2 was
not retuned against it. The ten original maps average 48.175% land versus
engine 47%; rivers average 3.635% versus 3.4312%. Every biome passes the
declared `max(0.75 percentage points, 25% of original mean)` budget. Land's
budget is 3 points, rivers' 1.5. Source/settings validation, independent
engine holdout, sample ranges/deviations and inspected renders are retained
in `worldgen-original-cohort.json` and `worldgen-v2-expanded.json`.

This meets a proposed practical reading of #90's written land/biome-spread
acceptance, for one controlled size/settings profile. It does **not** establish
distribution identity or spatial parity. Coast-transition edges average
27.5906% original versus 10.1172% engine, same-terrain edges 50.6633% versus
69.0932%, and land-component count 7.2 versus 3.4219. Our geography is smoother.
The independent reviewer must assess these explicit limits against the issue
body; the report does not silently declare the original generator recreated.

All 89 occupied native regions in eight new RAM captures match table-word
+0/+2/+4 meanings (land, plains/grassland, water counts). Original region
assignment can associate coastal water with land and remains unported.
All 25 install save/configuration hashes were reverified after captures;
the oracle game is stopped. Raw saves/screenshots/RAM remain outside Git.
